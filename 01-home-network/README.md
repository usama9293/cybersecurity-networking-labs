# Project 1 — Home Network

A small home/office network built in Cisco Packet Tracer.

## Objective

Build a basic LAN with wired and wireless devices and configure the network for local communication.

## Devices

- Home Wireless Router
- Cisco 2960 Switch
- PCs
- Laptop
- Smartphone

## Concepts Practiced

- LAN
- Ethernet
- Wi-Fi
- IPv4
- Subnet Mask
- DHCP
- Default Gateway
- MAC Address
- Ping / ICMP
- Basic Network Troubleshooting
