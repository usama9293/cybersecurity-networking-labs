# Project 2 — Routed Network

A small routed network built in Cisco Packet Tracer.

## Objective

Build two separate IPv4 networks and enable communication between them using a Cisco router.

## Topology

- 1 × Cisco 2911 Router
- 2 × Cisco 2960 Switches
- 4 × PCs

## Network A

- Network: 192.168.10.0/24
- Router: 192.168.10.1
- PC0: 192.168.10.10
- PC1: 192.168.10.11

## Network B

- Network: 192.168.20.0/24
- Router: 192.168.20.1
- PC2: 192.168.20.10
- PC3: 192.168.20.11

## Concepts Practiced

- IPv4 addressing
- Subnet masks
- Default gateways
- Two separate networks
- Router interfaces
- Routing between networks
- Ping / ICMP
- Network connectivity testing
